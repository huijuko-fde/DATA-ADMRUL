# 통계작성의 변경승인 고시(사교육의식조사)
> 고시 · 행정규칙 · 시행 2015-01-05 · 공포 2015-01-05 · 제정

### 전문
1. 통계의 명칭 : 사교육의식조사 2. 통계작성기관의 명칭 : 교육부 3. 통계작성승인번호(작성승인일) : 제11212호(2007.09.21.) 4. 통계작성의 중지 연월일 : 2014. 12. 30. 5. 통계작성의 중지 사유 : 교육부-통계청간「사교육비조사 공동통계 작성」업무분장 협약이행(사교육의식조사는 사교육비조사로 통합)
